# Global Chess startup documentation moved

Global Chess owns its factory and lifecycle in its independent repository. Start Core with app.core_main:app; the legacy app.main entry point was removed.

See [GLOBAL_CHESS_SEPARATION.md](GLOBAL_CHESS_SEPARATION.md) for ownership and the
removal inventory. Consult the independent private Global Chess repository for
current implementation and deployment instructions. Source Git history retains
the earlier document; no application behavior was moved into Core.
